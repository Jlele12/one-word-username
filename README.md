One word, one username, one reward: the entrant's own make.fun handle — **le-le** — sent as that single word, nothing else.

`main.py` writes exactly that one word (1-30 chars, UTF-8) to `/output/entry.txt`.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
